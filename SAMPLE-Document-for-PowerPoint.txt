The MITG/DMID teams are 75% ready for structured Copilot adoption starting mid-June. Three foundational sessions are planned (Crawl, Walk, Run) with ~30 voluntary participants. SESSION PLAN OVERVIEW

Session 1: "Introduction to AI — Lighter Touch Hands-On" (1.5–2 hours)
Format: Show → Try → Reflect
Audience: All ~30 participants
Content: Plain-language AI overview, three demo + try moments anchored to real MITG/DMID use cases
Outcome: First Copilot experience, awareness, confidence to try on their own

Session 2A: "M365 Copilot Productivity Deep Dive" (1.5–2 hours)
Format: Demo → Replicate → Refine
Audience: Voluntary self-selected group
Content: Copilot in Outlook, Word, Excel, PowerPoint, SharePoint; prompt engineering
Outcome: Practical M365 Copilot skills across all core apps

Session 2B: "Copilot Hands-On Workshop — Copilot-as-Interviewer" (2 hours)
Format: Copilot interviews each participant about their role; fully adaptive
Audience: Voluntary, role-agnostic
Content: Personalized use case exercises (each person gets custom prompts for their job)
Outcome: Personalized Copilot use cases + first real artifact per participant

Session 3: "Copilot Studio + AI Agents" (1.5–2 hours)
Format: Facilitator demos only, no hands-on agent building
Audience: Committed learners seeking certification
Content: Intro to Copilot Studio, pre-built vs. custom agents, knowledge sources, publishing
Outcome: Ability to explore agents, formal Microsoft certification pathway

CRITICAL SUCCESS FACTORS

1. Leadership Message
Teams need to hear from Tyrone / Matthew Forsage: "AI adoption is strategic. We expect you to spend 1 hour in Session 1 and 2-3 hours in Sessions 2/3. Return on investment: faster reports, more time on strategic work, better decisions."

2. Hands-On Practice
No "death by PowerPoint." Every concept must have an immediate try. 3-5 minute free experimentation per block.

3. Role-Specific Relevance
Generic Microsoft examples don't work. Every use case demo must show MITG/DMID work (contracts, budgets, compliance, email threads from their jobs).

4. Sample Data
Students need realistic files to practice with: sample emails, project documents, meeting transcripts. Not contrived examples.

5. Clear Next Steps
After Session 1, what's the path to Session 2? Self-signup? Nomination? How do people know if they're interested?
