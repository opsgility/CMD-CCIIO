# Demo + Try Exercises for Session 1

This folder contains standalone demo + try exercises for CCIIO AI Adoption Session 1. Students can access these directly during or after the session for hands-on practice.

---

## Files in This Set

### Markdown Exercises (GitHub-Hosted)

These files are designed to be hosted on GitHub for easy sharing via link. Students can open them, copy the prompt, and paste directly into Copilot.

1. **01-Email-Summarization-2on2.md**
   - **Use Case:** Outlook email thread → 2-on-2 status update
   - **Time:** 5-10 minutes

   - **ROI:** Save 2-4 hours/week on status update drafting
   - **Includes:** Setup, prompt, sample email thread, follow-up prompts, tips

2. **02-PowerPoint-from-Sources.md**
   - **Use Case:** Word document or text → PowerPoint deck
   - **Time:** 8-12 minutes
   - **Audience:** Anyone presenting to stakeholders (PMs, analysts, leadership)
   - **ROI:** Reduce deck creation time by 60-80%
   - **Includes:** Setup, two prompt options, sample doc, follow-ups, tips

3. **03-Meeting-Transcript-to-SOP.md**
   - **Use Case:** Meeting transcript → Step-by-step SOP / job aid
   - **Time:** 8-12 minutes
   - **Audience:** Process owners, team leads, anyone documenting workflows
   - **ROI:** Reduce SOP drafting time by 60-80%
   - **Includes:** Setup, prompt, sample transcript, follow-ups, use cases, tips

## How to Use in Session 1

### Setup (5 minutes)
- Project the GitHub links on screen
- Give each participant the three URLs
- Tell them: "During the demo + try blocks, use these links. Copy the prompt, paste into Copilot. If you don't have your own document, use the sample files."

### During Demo + Try Block (3-5 min per app)
1. **Facilitator demos** the concept in one app (Outlook, PowerPoint, or Word)
2. **Participants try** on their own machine:
   - Open the markdown file link
   - Copy the prompt from the "Copy & Paste" section
   - Paste into Copilot
   - Experiment for 3-5 minutes
3. **Group reflects** (2 min):
   - "What surprised you?"
   - "Did Copilot capture what you expected?"
   - "Would you use this for your real work?"

## Customization Ideas

1. **Add your own examples**
   - Replace sample email thread with a real recent email from your team
   - Replace budget doc with an actual MITG/DMID project document
   - Replace meeting transcript with a real contract/compliance discussion

2. **Adjust timelines**
   - If participants are slow, give 7-8 minutes per demo + try
   - If fast, add "What to try next" follow-up prompts

3. **Add role-specific versions**
   - COR-specific 2-on-2 email thread
   - Budget analyst's expense report to dashboard prompt
   - Analyst's data interpretation example for Excel

4. **Layer in security messaging**
   - Add a "Hallucination check" step after each demo
   - Remind participants to verify numbers, dates, and decision owners
   - Highlight what to do if Copilot makes something up

## Tips for Facilitators

- **Go first:** Demo each one yourself before Session 1 so you're comfortable with the flow
- **Have a backup:** If Copilot Chat isn't working, have the sample files ready to discuss instead
- **Celebrate small wins:** "You just created what would have taken 30 minutes in 10 minutes!"
- **Normalize iteration:** "Your first prompt didn't work perfectly—that's normal. Try a follow-up."
- **Reflect on ROI:** "This email thread took me 15 minutes to summarize. Imagine doing 5-10 of these per week."

## FAQ

**Q: Can students do these exercises outside of Session 1?**
A: Yes! These are standalone. They can be used in Sessions 2A/2B, or for self-paced practice after the session.

**Q: What if a student doesn't have access to Copilot in their app?**
A: They can still use Copilot Chat directly (if they have a license) or observe a peer doing the exercise.

**Q: Can I modify the prompts?**
A: Absolutely. Customize them for your team's specific workflows, roles, or terminology.

**Q: How do I know if students are really getting value?**
A: Ask them: "Would you use this in your real work?" and "How much time would this save you?" Their answers are better than any metric.
